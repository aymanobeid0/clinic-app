## Transport contract

Shared input schema `issueInvoiceSchema` and `Invoice`, `InvoiceItem`, `PlanSummary`, `InvoiceOutput`, `PlanSummaryOutput` types live in `packages/contracts/src/index.ts`. Ready current authenticated sessions required everywhere; existing Origin/CSRF defenses protect POST. UUIDs canonicalized; response money uses exact integer minor-unit strings, without rounding or conversion.

| Route | Behavior |
| --- | --- |
| `POST /api/billing/:patientId/invoices` | Explicit command `{commandId, chargeIds:[1..100 UUIDs]}`. Requires `invoices.issue` or manager authority. Every charge must belong to that patient, visible own-work scope, be clinically completed, fully paid and reconciled to confirmed price. One currency per invoice; eligible charges can span plans. Returns retained invoice. |
| `GET /api/billing/:patientId/invoices` | `billing.read` or manager: visible retained invoices. |
| `GET /api/billing/:patientId/invoices/:invoiceId` | Same scope: retained invoice, 404 for invisible/missing documents. |
| `GET /api/billing/:patientId/invoices/:invoiceId/print` or `/download` | French structured `{title:'Facture',invoice}` with retained identity/content. Requires `billing.read` plus corresponding `financial.print`/`financial.download`, or manager. No installment/payment breakdown on invoices. |
| `GET /api/billing/:patientId/plans/:planId/summary` | `billing.read` or manager. Latest plan must be completed. Returns current read-only summary: procedures, exact charged/paid/due totals, existing invoice references and payment/allocation references. Creates no charge, receipt, invoice or command. |
| Same summary route plus `/print` or `/download` | Same separate output grants. French `{title:'Récapitulatif du plan terminé',summary}`. Product rendering remains deferred. |

Invoice items retain charge, plan, item and performer references, completion date, whole adjusted charge amount, procedure name/teeth. Invoice snapshots retain patient number/name, clinic name, actor/time and independent clinic/UTC-year `INV-YYYY-NNNNNN` number. Receipt series/content remains unchanged. Current staff delivery hides clinical descriptions unless separately authorized; persistence retains full content even when a restricted staff issuer creates the invoice. Doctors require active patient access/action grant and own performed work; whole mixed-performer invoices are withheld, including in lists/outputs. Summary `scope:'own_work'` totals/procedures exclude other work, and mixed invoice references remain hidden; general authority gets `whole_plan`. Staff summaries hide clinical title/names/teeth. Permission/patient access is rechecked before replay. Historical-only/disabled accounts cannot use current operations.

400: malformed payload, duplicate/empty selections, mixed currencies. 401: missing current session. 403: missing current action/output grant or doctor patient scope. 404: invisible patient/charge/plan/invoice. 409: incomplete/unpaid/unreconciled work, already invoiced charge, changed actor/payload command reuse, non-completed plan summary. Unexpected persistence failure: sanitized 500 and whole transaction rollback. Successful identical command retry retains its original identity/year/content; callers retain commandId after uncertain responses. Distinct overlapping commands conflict rather than creating a second invoice.
